# Knowledge (최소)

제품 wiki/canvas는 범위 밖이다. 지식은 다음 순서로:

1. Active 티켓 `get_ticket` / `get_comments` / 첨부(`plan.md` 등)
2. 관련 repo 문서 (`ARCHITECTURE.md`, `DESIGN.md`, `ROADMAP.md`)
3. 필요 시 웹 검색 (외부 사실만)

작업 후 재사용할 요약은 Active 티켓 코멘트에 남긴다. 승격·전사 wiki push는 하지 않는다(km 최소 역할도 티켓 정리 중심).
